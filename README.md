#Task Manager

Web UI to manage in-progress/done/to-do tasks.

## Requirements:
- Python3
- Flask to serve data
- Javascript to work on client side
- Local server, using Python's default

## Issues:
- On Next tasks group a new task cannot be added. Client side might work but nothing is uploaded to server. Still working on a way. So temporarily, tasks for next week can be added on current week group. On next server reload the task will be moved to "next-week".

- Date displayed on current week group might be wrong, usually by the end of the month. This issue appears when showing dates for every day.
